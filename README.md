# policy-diff-analyst

Claude Code skill for comparative analysis of Chinese policy documents (政府工作报告、中央经济工作会议公报、五年规划纲要等).

Outputs a Word analysis article (3 styles) + Excel data tables + a folder of PNG charts.

See [docs/superpowers/specs/2026-04-16-policy-diff-analyst-design.md](docs/superpowers/specs/2026-04-16-policy-diff-analyst-design.md) for the design spec.
