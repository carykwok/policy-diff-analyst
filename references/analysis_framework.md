# 政策文件深度解读方法论

本文件是 LLM 在 SKILL.md Step 4 写作分析文章时的核心方法论指引。从中金、华泰、中信、国君、粤开、德勤等头部机构的政策研报中提炼而来。

**核心原则：每个差异点必须走完"是什么→为什么→所以呢"三步，裸列差异不是分析。**

---

## 一、定调分析层（Tone Setting）

政策文件的核心信号首先体现在"定调"措辞中。定调词不是虚词——每个定调词背后对应明确的政策力度区间。

### 1.1 宏观总基调演变谱系

| 定调表述 | 含义 | 历史出现 |
|---------|------|---------|
| 稳字当头 | 守底线，不折腾 | 2022 |
| 稳中求进 | 稳是主旋律，进是方向 | 2023、2025 |
| 以进促稳、先立后破 | 进的优先级高于稳 | 2024（中央经济工作会议首提） |
| 进中求好 | 追求质量而非速度 | 2026 |

**解读方法**：对比当年与上年的总基调，判断政策取向是趋紧（防风险）、趋松（稳增长）还是结构性转换。

### 1.2 财政政策力度谱系

| 表述 | 力度 | 信号 |
|------|------|------|
| 积极的财政政策 | 常规扩张 | 延续基调 |
| 更加积极的财政政策 | 加力扩张 | 明确加码 |
| 加力提效 | 扩张+效率约束 | 有节制地加码 |
| 适度加力、提质增效 | 温和扩张 | 空间收窄 |

### 1.3 货币政策力度谱系

| 表述 | 力度 | 信号 |
|------|------|------|
| 稳健的货币政策 | 中性 | 常规操作 |
| 灵活适度 | 中性偏松 | 有降准降息空间 |
| 精准有力 | 结构性宽松 | 定向工具为主 |
| 适度宽松 | 明确宽松 | 2010年以来首提（2024.12中央经济工作会议） |

**写作要求**：文章开篇必须判断"总基调 + 财政定调 + 货币定调"三者组合所传递的整体政策取向，并与上年做对比。

## 二、量化目标解读层（Quantitative Targets）

量化目标不是数字搬运——重点在于目标设定本身传递的信号。

### 2.1 核心量化指标对比框架

| 指标 | 关注点 | 信号解读方法 |
|------|-------|------------|
| GDP 增速目标 | 具体值 vs 区间 vs "左右" | 区间目标=弹性空间大=给改革留余地（如2026年首次采用4.5%-5%区间） |
| CPI 目标 | 上调/下调 | 目标下调=承认通缩压力=需要需求侧刺激 |
| 赤字率 | 突破3%红线与否 | 突破=非常规财政扩张信号（2025年首次4%） |
| 专项债额度 | 增量大小 | 增幅>5000亿=明确基建发力 |
| 特别国债 | 规模与用途变化 | 新增用途=新政策优先级（如消费品以旧换新） |
| 城镇新增就业 | 目标值变化 | 上调=信心较足；维持=守底线 |
| 单位GDP能耗 | 目标松紧 | 放松=经济优先于减碳 |

### 2.2 量化指标解读三步法

1. **数字本身**：目标值、同比变化方向和幅度
2. **设定逻辑**：为什么定这个数？与实际完成值的差距说明什么？（如2024年CPI目标3%但实际只有0.2%→2025年下调至2%说明正视了通缩现实）
3. **市场含义**：这个目标对资产配置意味着什么？（如赤字率4%→利率债供给压力→收益率上行压力）

## 三、措辞变化信号层（Wording Signal）

措辞变化是政策分析的微观基础。以下是四类核心信号及其解读方法。

### 3.1 新增表述（首次提出/首次写入）

**识别方法**：在旧版中搜索不到完整匹配的新表述。

**解读维度**：
- **来源追溯**：该表述最早出现在哪里？（通常路径：领导人讲话 → 政治局会议 → 中央经济工作会议 → 政府工作报告。越靠后=越正式=越确定要落地）
- **定位层级**：是写在"总体要求"还是"具体任务"中？（前者=纲领性方向，后者=已有执行路径）
- **配套程度**：有无跟随的量化目标或具体政策工具？（有具体工具=短期可落地，纯表述=中长期方向）

**示例**："新质生产力"在2024年报告首次出现且写在工作任务第一条→方向性新概念+最高执行优先级。

### 3.2 删除/不再提及的表述

**解读维度**：
- **主动淡化 vs 任务完成**：区分"不再强调"和"已经解决"（如"六稳六保"淡出=经济恢复后的常规回归，不是政策转向）
- **替代表述**：是否有新词替代了旧词？（如"房住不炒"被删除，但新增"构建房地产发展新模式"=换框架不是放松）
- **政策周期判断**：某些表述的消失反映阶段性任务完成（如"脱贫攻坚"→"乡村振兴"的衔接）

### 3.3 力度修饰词变化

这是强度评分的政策语义基础。力度修饰词不是文学修辞——它们在政策文件中有明确的强弱排序。

| 修饰词 | 力度等级 | 含义 |
|--------|---------|------|
| 坚决/全力/大力 | ★★★★★ | 最高优先级，不计成本 |
| 加快/深入推进/持续加大 | ★★★★ | 高优先级，强执行 |
| 积极/着力/扎实 | ★★★ | 中高，稳步推进 |
| 稳妥/有序/逐步 | ★★ | 谨慎推进，控制节奏 |
| 适当/合理/适度 | ★ | 有保留，可进可退 |
| 保持/维持/巩固 | ● | 中性，维持现状 |

**解读方法**：同一关键词前后年份修饰词变化 = 政策力度信号。"积极扩大内需"→"大力提振消费"= 力度升级一档，消费在政策排序中权重显著上升。

### 3.4 结构位置变化

章节排序在中国政策文件中具有明确的优先级语义：

- **L1 章节排序前移** = 整体战略优先级提升（如"扩大内需"从2024年的第三项工作任务→2025年的第二个独立章节）
- **L2 子章节排序前移** = 在同一大方向下，具体领域的执行优先级变化（如"消费"从工作任务三的（三）→（一））
- **独立成章 vs 合并章节** = 独立成章意味着从"附属议题"升级为"独立战略"

**写作要求**：结构变化必须在文章前部呈现，配合框架图，让读者先有"森林"再看"树木"。

## 四、政策传导与行业影响层（Transmission & Impact）

这是从"政策分析"到"投资分析"的关键跳跃。

### 4.1 政策传导链模型

```
政策表述 → 部委细则(3-6个月) → 行业准入/补贴/监管变化 → 企业行为 → 市场反应
```

**对每个核心差异项，需要推演**：
1. 哪个部委/哪些部门会负责执行？
2. 预期什么时间窗口出台细则？（两会后通常3-6个月）
3. 直接受益行业/间接受益行业是哪些？
4. 受损行业/受限行业是哪些？

### 4.2 行业配置分析框架（C2 判断依据）

| 配置等级 | 判断标准 |
|---------|---------|
| **超配** | 新增重点表述 + 力度升级 + 有量化目标/资金配套 + 结构位置前移 |
| **标配** | 延续表述 + 力度不变 + 无新增亮点也无负面 |
| **低配** | 表述淡化 + 力度降级 + 监管收紧信号 + 删除相关目标 |

**必须给出的行业维度**：
- 直接受益行业（政策点名）
- 间接受益产业链（上下游传导）
- 可能受限行业（"规范""整治""风险"等负面修饰词出现的领域）

### 4.3 市场风格判断（C1 判断依据）

从政策组合推断市场风格偏向：

| 政策组合 | 市场风格倾向 |
|---------|------------|
| 宽财政 + 宽货币 + 保增长 | 顺周期/价值 |
| 紧财政 + 宽货币 + 调结构 | 成长/科技 |
| 宽财政 + 扩内需 + 促消费 | 内需/消费 |
| 防风险 + 紧监管 + 稳货币 | 防守/红利 |

## 五、历史语境与交叉验证层（Context & Cross-Validation）

### 5.1 历史纵向对比

- 将当前表述放在 3-5 年纵向序列中：是"新提法"（全新概念）？"升级提法"（存在→强化）？"回归提法"（消失后重现）？还是"常规提法"（每年都有）？
- 引用具体年份的原文对照（"2024年报告原文：'…'；2025年改为：'…'"）
- 识别"螺旋上升"模式：某些政策主题会经历"提出→试点→推广→常态化"的生命周期

### 5.2 横向交叉验证

将政府工作报告的信号与以下文件交叉印证：
- **中央经济工作会议**（上年12月）：工作报告是否完整承接了经济工作会议的部署？有无新增或弱化？
- **政治局会议**：年中政治局会议对上半年工作的判断是否与年初报告的基调一致？
- **货币政策执行报告**（央行季报）：央行的实际操作是否跟上了工作报告的定调？
- **部委工作会议**：具体领域的部委部署是否落实了报告的目标？

### 5.3 国际环境变量

近年政策文件越来越多地回应外部环境（如中美贸易摩擦、地缘冲突、全球通胀/通缩），需要：
- 识别"外部挑战"表述的力度变化
- 判断"内循环 vs 双循环"侧重点的漂移
- 评估外部变量对政策空间的约束

## 六、写作质量标准

### 6.1 每个核心差异项的标准输出格式

```
【差异项】：XX 表述从"…"变为"…"
【信号解读】：这一变化说明……（定调/力度/优先级判断）
【历史对标】：这是自 20XX 年以来首次/时隔 X 年再次/连续第 X 年……
【传导推演】：预计将由 XX 部委牵头，XX 个月内出台细则，直接利好 XX 行业……
【置信度】：高/中/低（给出判断依据）
```

### 6.2 文章整体结构要求

无论哪种风格（投研/媒体/大白话），文章必须包含以下核心板块：

1. **框架概览**（使用 structure_diff 数据）：先给读者一个"全局地图"
2. **定调判断**：宏观/财政/货币三重定调组合及其含义
3. **量化目标对比表**（使用 quantitative_comparison 数据）：关键数字变化及其信号
4. **核心措辞变化解读**（TOP 10 差异项深度分析）：不是罗列全部差异，而是挑最重要的 10 个深入解读
5. **行业影响推演**：超配/标配/低配 + 传导逻辑
6. **风险与反向观点**：对核心判断的反面论证
7. **附录**：完整差异清单、原文对照

### 6.3 避免的写法

- ❌ 罗列差异不解读（"报告新增了 XX 表述"→然后？）
- ❌ 只说变了不说为什么（"赤字率从3%升至4%"→为什么要突破红线？意味着什么？）
- ❌ 泛泛而谈不给证据（"政策力度加大"→具体哪个词从什么变成什么？）
- ❌ 无视结构信号（只看词频不看章节位置变化）
- ❌ 没有置信度标注（每个判断都应标注信心水平）
- ❌ 缺少反向观点（单边叙事缺乏可信度）
