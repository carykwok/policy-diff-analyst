> 注：三中全会聚焦改革，层级重在"改革工具/领域"维度。

## Layer keyword maps

- 全面深化改革、进一步全面深化改革、中国式现代化

### A2 经济体制改革

## Strength scoring anchors (0–5 scale)

| 措辞 | 得分 |
|------|------|
| 坚决、坚定、彻底、根本、全面 | 5 |
| 大力、健全、深化、完善 | 4 |
| 加快、推进、构建、建立 | 3 |
| 稳步、有序、逐步、稳妥 | 2 |
| 探索、研究、试点 | 1 |
| (未提及) | 0 |

## Notes
- 三中全会特有的"健全"、"完善"、"深化"是核心改革动词，权重需高于一般"推进"。
- "探索、试点"在三中全会里是明确改革方向信号，但落地强度较弱，故评 1 分。
- 三中全会频率低（5 年一届），对比对象通常是上届决定（如二十届 vs 十九届），跨度大，关键词演进敏感。
