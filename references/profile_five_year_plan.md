# Profile: 五年规划纲要 (five_year_plan)

> 起草说明：按公开研究惯例（十三五/十四五纲要章节结构 + 中金/中信研究院五年规划解读框架）v1 草稿，待用户 review。
> 注：五年规划纲要文本量大（十四五 6 万余字、19 篇 65 章），层级集合在其他文档基础上扩展至 8 层以保留 MECE。

## Layer keyword maps

### A1 发展理念
- 创新、协调、绿色、开放、共享
- 高质量发展、中国式现代化、新发展格局、新发展阶段
- 社会主义现代化、2035 远景目标

### A2 科技创新
- 科技自立自强、国家战略科技力量、国家实验室
- 原创性引领性、基础研究、应用基础研究、关键核心技术
- 新质生产力、人工智能、量子信息、集成电路、生命健康、航空航天、深地深海
- 科技体制改革、人才强国、研发投入强度

### A3 现代产业体系
- 先进制造业、战略性新兴产业、未来产业
- 新能源、新材料、高端装备、智能制造、工业母机
- 数字经济、平台经济、产业数字化、数字产业化
- 传统产业改造升级、产业基础高级化、产业链现代化

### A4 国内大循环
- 扩大内需、最终消费、国内市场
- 现代流通体系、商品和要素流动、统一大市场
- 城乡融合、新型城镇化、县域经济
- 投资、有效投资

### A5 区域协调
- 京津冀、长三角、粤港澳大湾区、成渝、黄河流域、长江经济带
- 西部大开发、东北振兴、中部崛起、东部率先
- 海洋强国、海洋经济、沿海沿边沿江

### A6 对外开放
- 高水平对外开放、制度型开放
- 一带一路、RCEP、自由贸易试验区、海南自贸港
- 外资、外贸、服务贸易、数字贸易
- 人民币国际化

### A7 安全发展
- 总体国家安全观、统筹发展和安全
- 粮食安全、能源安全、产业安全、金融安全、生态安全
- 关键产业链供应链自主可控、国产替代
- 国防和军队现代化

### A8 生态民生
- 碳达峰、碳中和、双碳、美丽中国
- 绿色低碳、生态文明、环境质量、碳排放强度
- 教育、医疗、养老、生育、住房
- 共同富裕、居民收入、中等收入群体、乡村振兴

## Quantitative keys

量化指标（Sheet 1「指标对比」用，五年规划特有的长期目标指标）：
- GDP、人均 GDP、国内生产总值
- 全员劳动生产率、研发投入强度、R&D 经费
- 常住人口城镇化率、数字经济核心产业增加值
- 单位 GDP 能耗、单位 GDP 二氧化碳排放、非化石能源
- 人均预期寿命、居民人均可支配收入、基本养老保险参保率
- 粮食综合生产能力、能源综合生产能力

## Notes
- 五年规划是战略性文件，"加快"在此语境下权重可能高于日常报告（考虑在 review 时上调至 4）。
- "研究、试点"不是弱表述而是战略储备，在五年规划里常指下一步系统性推进的信号。
- 章节化程度高，section detection 建议按篇/章两级拆分（后续可优化，本 profile 不涉及）。
