# Profile: 货币政策执行报告 (monetary_policy_report)

> 起草说明：按公开研究惯例（PBoC 《货币政策执行报告》各季度结构 + 中金固收/中信固收/兴证固收惯用拆解框架）v1 草稿，待用户 review。
> 注：PBoC 每季度发布一份，对比维度以"工具组合 + 市场传导"为核心，不设 A7 结构增量层（季度报告节奏短，结构增量意义弱）。

## Strength scoring anchors (0–5 scale)

| 措辞 | 得分 |
|------|------|
| 坚决、坚定、切实 | 5 |
| 大力、加大、显著 | 4 |
| 加强、强化、提升、着力 | 3 |
| 保持、维持、继续、稳定 | 2 |
| 关注、研究、适度、合理 | 1 |
| (未提及) | 0 |

## Notes
- 货政报告的"保持、维持"不是虚词——是 PBoC 表达"不变"的官方态度，因此评 2 分（中性偏积极）而非 0。
- "适度"在货政报告里常与"宽松/紧缩"搭配但不单独表态，评 1 分。
- A3 价格工具的利率数字（如 LPR 3.45% → 3.10%）是核心对比对象，量化指标层能捕捉出现频率但不能捕捉数值变化——这是后续需要扩展的能力（当前 profile 不解决，作为 backlog 标注）。
- 季度环比对比（Q1 vs Q2）和年度对比（2024Q1 vs 2023Q1）信号差异大，用户应在 Mode A 输入时指明。
