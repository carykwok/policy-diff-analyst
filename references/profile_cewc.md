# Profile: 中央经济工作会议 (cewc)

> 起草说明：按公开研究惯例（中金/中信/国君/兴证等卖方宏观年度展望惯用框架 + 历届 CEWC 公报高频术语）v1 草稿，待用户 review。

## Layer set

- A1 总基调
- A2 政策工具
- A3 重点任务
- A4 风险底线
- A5 改革开放
- A6 民生保障
- A7 结构增量

## Layer keyword maps

### A1 总基调
- 稳中求进、稳中有进、以进促稳、稳字当头、先立后破
- 高质量发展、中国式现代化、新质生产力
- 五个必须、五个统筹

### A2 政策工具
- 财政：积极的财政政策、适度加力、提质增效、赤字率、专项债、超长期特别国债、中央财政
- 货币：稳健的货币政策、灵活适度、精准有效、合理充裕、社融、广义货币
- 产业：现代化产业体系、产业政策、新型工业化
- 科技：科技政策、创新驱动、基础研究、关键核心技术
- 社会：社会政策、就业优先、兜牢底线

### A3 重点任务
- 扩内需：扩大国内需求、内需、消费、投资、大宗消费
- 现代化产业：战略性新兴产业、未来产业、传统产业改造、制造业
- 科技创新：人工智能、集成电路、量子、生物制造、商业航天、低空经济
- 数字经济、平台经济、绿色低碳、碳达峰、碳中和

### A4 风险底线
- 房地产：房地产市场、保交楼、保交房、三大工程、商品房、租赁住房
- 地方债：地方政府债务、隐性债务、化债
- 金融：中小金融机构、系统性金融风险、防范化解
- 三大风险（房地产/地方债/中小金融机构）

### A5 改革开放
- 改革：国资国企、民营经济、要素市场化、全国统一大市场
- 开放：高水平对外开放、稳外资、稳外贸、制度型开放、一带一路、自贸试验区

### A6 民生保障
- 就业：高质量充分就业、重点群体、高校毕业生、农民工
- 社保：基本养老、医保、生育支持、托育
- 分配：居民收入、中等收入群体、共同富裕
- 粮食安全、能源安全

## Quantitative keys

量化指标（Sheet 1「指标对比」用）：
- GDP、国内生产总值、经济增长
- 赤字率、赤字、专项债、超长期特别国债
- CPI、居民消费价格
- 社融、广义货币、M2
- 城镇新增就业、调查失业率
- 居民收入、居民人均可支配收入

## Strength scoring anchors (0–5 scale)

| 措辞 | 得分 |
|------|------|
| 坚决、坚定、全面 | 5 |
| 大力、着力、切实、加力 | 4 |
| 加快、积极、深入、提质 | 3 |
| 稳妥、有序、逐步、适度 | 2 |
| 审慎、研究、探索 | 1 |
| (未提及) | 0 |

## Notes
- CEWC 措辞微调往往释放重大信号（如"稳中求进"→"稳中求进、以进促稳、先立后破"），强度维度敏感度需保持一致。
- "三大风险"近三年均列明，作为 A4 基准锚点。
