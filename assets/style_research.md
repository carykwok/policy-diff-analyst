# Style: 投研派 (research)

Audience: institutional investors / sell-side analysts. Goal: rigorous, citable.

**写作前必须先读 `references/analysis_framework.md`，按其方法论展开分析。**

## Structure (strict)

1. **摘要** (≤200 字)：一句话总基调判断 + 3 条核心政策信号
2. **框架概览**：章节结构对比图（L1+L2），标注位置变化方向箭头，让读者一眼看到"森林"
3. **定调判断**：宏观总基调 + 财政定调 + 货币定调三重组合，参照 analysis_framework §一 的谱系表做纵向对比
4. **量化目标对比表**：GDP/CPI/赤字率/专项债/特别国债等核心指标，每个指标按"数字→设定逻辑→市场含义"三步法展开（参照 §二）
5. **TOP 10 核心措辞变化深度解读**：挑选信号最强的 10 个差异项，每个按标准五段式输出：差异项 → 信号解读 → 历史对标 → 传导推演 → 置信度（参照 §三、§六.1）
6. **行业影响矩阵**：
   - C1 市场风格判断（成长/价值·内需/外需·进攻/防守）+ 判断依据（参照 §四.3）
   - C2 行业配置：超配/标配/低配三档，每档列出板块 + 政策证据 + 传导逻辑（参照 §四.2）
   - C3 交易节奏：预期→落地→兑现三阶段的时间窗口
7. **分维度论证** (按 profile layer 依次展开，每层：结论→原文对比证据→信号解读→行业传导)
8. **风险提示与反向观点**：对每个核心判断给出反面论证（不是一句话免责，而是真正的对立逻辑）
9. **附录**：
   - 完整差异清单表
   - 量化指标全表
   - 新旧版本原文全文

## Language
- 术语密度高（宏观、货币、财政、专项债、新质生产力…）
- 数据优先，段落常以数字开头
- 避免感情色彩；用"我们判断"而非"我觉得"
- 每个判断带置信度（高/中/低）和判断依据
- 引用原文时标注出处："2024年报告原文：'…'；2025年改为：'…'"
- 历史对标必须给出具体年份："这是自2010年以来首次…"
