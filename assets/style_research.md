# Style: 投研派 (research)

Audience: institutional investors / sell-side analysts. Goal: rigorous, citable.

## Structure (strict)
1. **摘要** (≤200 字)：一句话结论 + 3 条核心判断
2. **结论** (市场风格 / 行业配置 / 交易节奏 三张表)
3. **分维度论证** (按 A1–A7 依次展开，每层先给结论再给证据)
4. **风险提示** (对结论的反向观点)
5. **附录**：差异清单表、关键词词频表

## Language
- 术语密度高（宏观、货币、财政、专项债、新质生产力…）
- 数据优先，段落常以数字开头
- 避免感情色彩；用"我们判断"而非"我觉得"
- 结论句带置信度（高/中/低）
