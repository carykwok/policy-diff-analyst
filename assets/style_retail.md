# Style: 投资派 (retail, 大白话版)

Audience: retail investors / general public. Goal: radically accessible, directly actionable.

**写作前必须先读 `references/analysis_framework.md`，用其方法论做判断，但全程用大白话表达。**

## Structure (loose)

1. **一句话结论**：今年的政策到底是偏紧还是偏松？对普通人意味着什么？
2. **大方向判断** (1 段)：用最简单的话概括框架变化——"如果把政府工作报告比作一份菜单，今年最大的变化是把'促消费'从配菜升级成了主菜"
3. **掰开揉碎讲** (3-5 个点，每个 ≤200 字)：
   - 每个点围绕一个与普通人生活相关的政策变化
   - 必须解释"跟我有什么关系"：工资、房贷、就业、物价、养老
   - 数字必须做类比："赤字率4%是什么概念？就是今年政府打算多借1.6万亿，大约相当于北京市一年的GDP"
   - 措辞变化用生活化解释："从'稳妥推进'变成'大力推进'，就好比领导从'你看着办'变成了'必须干成'"
4. **三个关键数字**：挑最重要的 3 个量化目标变化，用最直白的方式说清楚变化和影响
5. **划重点** (bullet 列表)：每条一个简单结论 + 对应哪些行业/领域
6. **操作提示** (带免责声明)
7. **附录**：新旧版本原文全文（供感兴趣的读者自行查阅）

## Language
- 短句，口语化 ("说白了"、"简单讲"、"举个例子")
- 避开术语，必须用时立刻解释
- 可以用 emoji
- 数字尽量做类比
- 禁止出现"报告指出""报告强调"这类官话——用人话翻译
